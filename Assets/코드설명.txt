 2. C:\Users\a3435\NeoSurvive\Assets\Scripts\Hacking\HackingSystem.cs

 핵심 역할
해킹 시스템의 싱글톤 매니저입니다. 해킹 UI 패널 관리, 캐릭터 타입(해커/사이보그)에 따른 해킹 방식 분기, 미니게임 시작/종료, 포위 패턴 시 해킹 오브젝트 스폰을 담당합니다.

 주요 필드/속성/의존성
- 싱글톤: Instance
- UI: hackingUIPanel, 5개 미니게임 루트(NumberSequence_Root 등), CyborgHacking_Root
- 프리팹: 5종 해킹 오브젝트 프리팹 (터렛, 전기울타리, 새틀라이트, 시냅스 서버, 마그네틱 비컨)
- 설정: spawnRadius, cyborgZoneRadius, cyborgTotalTime
- 상태: currentMinigame, isHacking, isHacker
- 의존: GameManager(캐릭터 타입), Player, HackingMinigameBase 파생 5종, Unity UI(Slider, TextMeshProUGUI)

 주요 메서드 흐름
1. Start() — UI 패널 하위 루트 Transform 탐색 후 전부 비활성화. GameManager에서 선택 캐릭터가 Hacker인지 확인.
2. SpawnRandomHackableObject() — 플레이어 주변 spawnRadius 내에 5종 프리팹 중 랜덤 1개 Instantiate. (실제 스폰은 PhaseDirector가 별도로 수행하는 경우도 있음)
3. StartHacking(objectType, onSuccess, onFailure, hackPosition) — 해킹 중복 방지 후 UI 패널 활성화.
   - 해커: Time.timeScale = 0 → StartMinigame() → 타입별 미니게임 루트 활성화 + GetOrAddMinigame<T>() + SetPreMadeUI() + Initialize()
   - 사이보그: StartCyborgHacking() — 미니게임 없이 수비 존 방식
4. CyborgHackingCoroutine() — 10초 제한, 1초당 20% 자동 진척. Physics2D.OverlapCircleAll로 Enemy 태그 감지 시 진척 정지. LineRenderer 원형 수비 영역 시각화(청록/빨강).
5. EndHacking() — 해커만 timeScale 복구, 사이보그 코루틴/존 비주얼 정리, 모든 루트·패널 비활성화.

 다른 시스템과의 연결
- HackableObject: 해커가 E키로 StartHacking() 호출
- GameManager: 캐릭터 타입 판별
- 맵 기믹: CargoDropCrane, SteamVentZone 등이 직접 StartHacking() 호출
- PhaseDirector: 포위 패턴 시 해킹 오브젝트 스폰 (HackingSystem과 별도 경로)

 주의할 동작이나 설계 의도
- 해커 미니게임은 Time.unscaledDeltaTime 사용(시간 정지 대응).
- 사이보그 해킹은 두 경로 존재:
  1. HackableObject.HandleCyborgCapture — 범위 내 체류 점령(이 시스템 미사용)
  2. HackingSystem.StartCyborgHacking — 외부/직접 호출 시 수비 존 방식
- UI 자식은 이름 기반 탐색(FindSlider, FindChild) — 에디터 계층 구조와 이름이 맞아야 합니다.
- GetOrAddMinigame은 런타임에 컴포넌트를 AddComponent하므로, 재시작 시 상태 잔존에 주의.


 3. C:\Users\a3435\NeoSurvive\Assets\Scripts\Hacking\HackableObject.cs

 핵심 역할
월드에 배치되는 해킹/점령 대상 오브젝트입니다. 플레이어 근접 감지, 캐릭터별 상호작용(해커 E키 미니게임 / 사이보그 범위 점령), 성공·실패 처리, VFX, 효과 발동을 통합 관리합니다.

 주요 필드/속성/의존성
- 설정: objectType, hackRange, psychoIncreaseOnFail
- VFX: idleVfxPrefab, failVfxPrefab, failVfxLifetime, vfxScale, 정렬/스프라이트 숨김 옵션
- 사이보그 점령: canCapture, captureTime, resetCaptureWhenOutOfRange, CaptureProgressUI
- 이벤트: OnActivated (SynapseServer/MagneticBeacon Effect가 구독)
- 상태: canHack, isHacked, isCaptured, captureProgress, cachedPlayer
- 의존: HackingSystem, Player, CharacterType, GameAnalyticsTracker, 각 Effect 클래스

 주요 메서드 흐름
1. Update() — 0.1초 간격 CheckForPlayer(), 해커 입력/사이보그 점령 처리. IsActivated(해킹/점령 완료) 후 종료.
2. CheckForPlayer() — 1초마다 FindObjectsOfType<Player>() 갱신. hackRange 이내면 canHack = true.
3. 해커 경로: HandleHackerInput() → E키 → StartHacking() → HackingSystem.StartHacking() + 분석 이벤트
4. 사이보그 경로: HandleCyborgCapture() — 범위 내 체류 시 captureProgress 증가 → CaptureProgressUI 갱신 → 100% 시 CompleteCapture()
5. OnHackingSuccess() — isHacked = true, 분석 기록, ActivateEffect()
6. OnHackingFailed() — 분석 기록, Fail VFX, Player.AddPsychoCorruption(psychoIncreaseOnFail)
7. ActivateEffect() — OnActivated 이벤트 발행 후 타입별 Effect:
   - SecurityTurret / ElectricFence / SatelliteUplink → switch에서 직접 Activate()
   - SynapseServer / MagneticBeacon → switch 미포함, Effect가 OnActivated 구독으로 자동 실행
8. HideVisuals() — 스프라이트·콜라이더 비활성, 컴포넌트 enabled = false

 다른 시스템과의 연결
- HackingSystem: 해커 미니게임 시작
- CaptureProgressUI: 사이보그 점령 바
- GameAnalyticsTracker: 상호작용/결과 추적
- Player: 사이코 잠식도 증가
- Effect 5종: 성공 시 전투 효과 발동

 주의할 동작이나 설계 의도
- 이중 Effect 활성화 패턴: 터렛/울타리/새틀라이트는 switch 직접 호출, 시냅스/비컨은 이벤트 기반. Effect 컴포넌트는 프리팹에 미리 붙어 있어야 Awake에서 구독 가능.
- 사이보그 HackableObject 점령과 HackingSystem 사이보그 수비 존은 별개 메커니즘.
- FindPlayers()는 첫 번째 Player만 사용 — 멀티플레이 미지원 가정.
- 실패 시 idle VFX 제거 + fail VFX 재생, 성공 시 idle VFX 제거.

- PickAll 모드에서 카드를 순서 무관하게 클릭 가능; 카드만 숨기고 패널은 마지막까지 유지.
