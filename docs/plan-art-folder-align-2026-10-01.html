아트 폴더를 코드 ID에 맞추는 이동표

기준 이름은 시트 카탈로그와 프리팹에 이미 있는 ID입니다. BlastBreath, BoltLauncher처럼 붙여 씁니다.

2026-10-01에 GUID 참조를 다시 세었습니다. 같은 그림이 두 폴더에 있으면, 실제로 애니·프리팹이 물고 있는 쪽만 남깁니다. 참조 0인 사본은 옮기지 않고 지웁니다.

이동은 유니티 Project 창에서 합니다. .meta가 같이 가야 GUID가 유지됩니다. 탐색기에서 옮기지 않습니다.

1. 사이보그 스프라이트 2. 사이보그 애니 3. 해커 스프라이트 4. 해커 애니 5. 셰이더 6. 맵·해킹·상자 그대로 두는 것 옮긴 뒤 효과 디메리트 확인

옮기면 생기는 효과

하는 일플레이에 보이는 것이유
폴더 이름 변경, 파일 이동 화면 변화 없음 씬·프리팹·애니는 경로가 아니라 GUID를 참조함. 코드에 이 폴더 경로 문자열은 없음. 셰이더도 이름 NeoSurvive/SpriteHitFlash와 머티리얼 GUID로 연결됨
참조 0인 잘리지 않은 사본 삭제 지금 재생되는 애니 유지 부스터, 중력 망치, 플라즈마 시트, 테슬라, 볼트, 파란 브레스는 애니 폴더의 잘린 시트가 실제로 재생 중. 지우는 쪽은 PPU 32에 조각이 1개인 사본
블래스트 12프레임 GUID 교체 하면 안 됨. 브레스 크기가 바뀜 BreathArea.prefab은 PPU 64 시트를 쓰고, 무기 VFX는 PPU 100 시트를 씀. 픽셀이 같아도 조각 위치가 다름
에너지 실드 PNG를 사이보그 폴더로 이동 오브와 실드 애니 유지 Energe Shield.anim과 ShieldOrb.prefab이 해커 폴더에 있는 그 GUID를 씀. 옮기면 GUID가 따라감. 사이보그 폴더의 같은 그림은 조각 1개·참조 0이라 지워도 화면은 그대로
Drone.png, lazer 1.png, 아이콘 이동 드론, 플라즈마 탄, 무기 선택 아이콘 유지 애니·AIDronePrefab·PlasmaPhotonProjectile·무기 데이터 에셋이 GUID로 연결
데이터 스크램블러 애니 폴더의 같은 PNG 삭제 스크램블러 이펙트 유지 조각 수와 위치가 같고, 애니가 물고 있는 건 스프라이트 폴더 GUID. 애니 폴더 사본은 참조 0
해킹 프롬프트 이름 끝 공백 제거 해킹 프롬프트 유지 HackingSystem은 프리팹을 GUID로 갖고, 만든 뒤 이름을 HackInteractPrompt(Runtime)으로 바꿈

탐색기에서 옮기면 .meta가 떨어져 GUID가 새로 생깁니다. 그러면 위 표와 반대로 애니·프리팹이 Missing이 됩니다. 유니티 안에서만 옮깁니다.

디메리트

플레이가 깨지는 경우는 블래스트 시트 GUID를 합치는 것뿐이었고, 그건 하지 않습니다. 아래는 화면은 유지돼도 생기는 손해입니다.

디메리트확인
참조 0인 사본을 지우면, 안 쓰이던 자르기(PPU 32, 조각 1개)가 작업 트리에서 사라짐. 깃 히스토리에는 남음 체인소 6프레임의 잘린 애니 시트는 그래서 삭제하지 않음
블래스트 12프레임은 두 장을 남기므로 폴더가 완전히 깔끔해지지는 않음. 한쪽 파일명은 겹치지 않게 바뀜 GUID 교체 시의 크기 변화보다 이 불편이 작음
폴더 이동 diff가 큼. 유니티를 연 채로 다른 사람이 같은 에셋을 고치면 충돌 게임 로직 변경은 없음
스프라이트 아틀라스, 타임라인, Resources.Load, 사운드 폴더 경로 아틀라스·타임라인 파일 없음. 사운드 경로는 Assets/Data/Sounds/Ingame이라 이번 이동과 무관. 아트 폴더 경로 문자열도 스크립트에 없음
vFavorites GUID로 저장됨. 지울 예정인 대표 GUID 4개는 즐겨찾기에 없음. 삭제 대상 전부를 즐겨찾기와 맞추지는 않음

세이브 파일 안의 에셋 참조, 레포 밖의 자료, .shadergraph 같은 다른 확장자는 보지 않았습니다. 그걸 포함해 디메리트를 전부 파악했다고 보지 않습니다.

확인

  • 유니티에서 Missing 스프라이트·애니·프리팹이 없는지
  • 사이보그 무기 10개, 해커 무기, 상자, 해킹 오브젝트, 맵 기믹이 플레이에서 보이는지
  • Art/Sprites/Characters/Cyborg와 Art/Sprites/Shader가 비어 사라졌는지
  • 기믹 폴더 이름이 스크립트·프리팹·애니에서 1EnvironmentGimmicks로 같은지

이 문서는 이동표입니다. 에셋은 아직 옮기지 않았습니다. 실행은 승인 뒤에 1번부터 순서대로 합니다.
