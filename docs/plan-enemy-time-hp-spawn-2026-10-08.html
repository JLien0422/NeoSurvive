제곱 HP 곡선 + 3분 스폰/쿨 스텝

손그림(끝만 수직)은 너무해서 제외. 0:00 basic HP 15, 15:00 315를 (시간/15분)²로 올림. 스폰은 0~3분 CSV 유지, 3·6·9·12분에 쿨 단축 + 정수 마리 증가.

1. 왜 코드가 필요한가

지금 HP는 페이즈 5단 계단입니다. 제곱 곡선을 CSV 페이즈 칸만으로는 못 만듭니다. 스폰 3분 스텝은 CSV만으로 됩니다.

  • HP: GameManager.CurrentPhase 배율 → GetGameTime() 제곱 보간
  • 스폰: enemy_spawn_phase2_5_table.csv 간격·마리 수만 교체
  • 이미 나온 적은 안 커짐. 새로 스폰되는 적만 그 시각 HP.

2. 범위

항목내용
HP 공식 basic 화면 HP = 36 × mul(t)
mul(t) = 15/36 + (315/36 − 15/36) × (t/900)²
t=0 → 15, t=900 → 315. shooter·rusher·bomber·tanker는 각자 CSV 기본 HP에 같은 mul.
0~3분 스폰 enemy_spawn_phase1_segments.csv 그대로
3분 이후 스폰 P2 0.30~0.45 / 3~4
P3 0.24~0.38 / 4~5
P4 0.18~0.32 / 5~6
P5 0.14~0.26 / 6~8
종류 가중치·포위 수치 유지

3. 파일

파일할 일
Assets/Data/Balancing/enemy_hp_scale.csv 페이즈 5줄 폐지. 한 줄 파라미터: durationsec,exponent,startmultiplier,endmultiplier → 900,2,0.416667,8.75
EnemyStatDB.cs / EnemyStatLoader.cs 시간 배율 로드. GetHpMultiplier(float gameTime)
EnemyController.cs 스폰 HP에 GetGameTime() 사용. 페이즈 배율 제거
enemy_spawn_phase2_5_table.csv 위 간격·마리만 수정
BalancingSheetCatalog.cs / sheet_catalog.json 02b 키를 새 컬럼에 맞춤. 구글 시트 탭은 로컬 CSV 우선, 시트 컬럼은 별도 맞추기

4. 수용 기준 (AC)

  • 0:00 근처 스폰 basic HP ≈ 15 (레이저 L1 12라 2타)
  • 3:00 신규 basic HP ≈ 27, 스폰 3~4마리, 간격 0.30~0.45. 예전처럼 1~2 / 0.4~0.8로 안 떨어짐
  • 6:00 ≈ 63 HP, 4~5마리 / 0.24~0.38
  • 9:00 ≈ 123 HP, 5~6 / 0.18~0.32
  • 12:00 ≈ 207 HP, 6~8 / 0.14~0.26
  • 14:50~15:00 신규 basic ≈ 315
  • 같은 시각 rusher HP = 28 × 같은 mul (0:00 ≈ 11.7)
  • 컴파일 에러 0. 무기·경험치·P1 스폰 세그먼트·포위 인원 불변
  • 에디터 시간 점프(2~6키) 후 새로 나온 적 HP가 그 시각 공식과 맞음

5. 비범위

  • 무기 CSV, 캐릭터 DPS, 경험치, 드랍
  • enemy_spawn_table.csv 레거시, enemy_stats.csv 기본 36 유지
  • 포위 인원·해킹 UX·종류 등장 타이밍(3분 shooter 등)
  • 이미 필드에 있는 적의 HP를 시간에 따라 갱신하지 않음
  • 손그림 4제곱/지수 곡선

구글 시트 02b 탭이 아직 phase,hpmultiplier면 싱크 시 로컬을 덮어쓸 수 있음. 이번 작업은 로컬 CSV+코드. 시트 탭 수정은 범위 밖(필요하면 후속).
