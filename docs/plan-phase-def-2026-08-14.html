0 전체 지도 (한눈에)

Phase한 줄위험코드 수정?PR
D Data는 거의 안 옮기고, 점검·빈칸·문서화. (필요 시 Catalog와 함께만 리네임) 중 기본 No / 리네임 시 Yes(경로 문자열) 1개

D Phase D — Data (및 잔여 씬/데이터 정렬)

D가 뭔가?

중위험 · 기본은 이동 최소

Assets/Data/는 CSV·ScriptableObject·사운드 정의 등 게임 수치/설정 데이터 창고입니다. 이미 Characters / Objects / Balancing / Traits / Sounds로 대체로 잘 나뉘어 있습니다.

왜 함부로 못 옮기나?
BalancingSheetCatalog.cs에 CSV 경로가 수십 개 하드코딩, SoundManager에 Assets/Data/Sounds/Ingame 기본값이 박혀 있음. 폴더만 옮기면 시트 동기화·사운드 로드가 깨짐 → 경로 문자열 수정 = 리팩터 경계.

D-1 — Data 인벤토리 + 이상 없음 확인 (필수)

먼저 함
하는 일
Data 트리와 Catalog/Sound 경로가 일치하는지 표로 고정. 빈 폴더(Data/Sounds/Lobby 등) 확인. Balancing/Objects/Weapons에 실파일이 있는지 확인(중복 자리인지).
파일
docs/ 점검 리포트 HTML (또는 worklog). 에셋 이동 없음.
코드
수정 없음

AC

  • Catalog에 적힌 모든 CSV 경로가 디스크에 존재
  • SoundManager 기본 경로 폴더 존재
  • 빈 Data 하위 폴더 목록이 문서에 있음

D-2 — 안전한 소형 정리만 (선택)

이동 거의 없음

해도 되는 것

  • 완전 빈 Data 하위 폴더 삭제 (경로 문자열에 안 나오는 것만)
  • Scenes/_Archive 설명 보강, 죽은 Build 엔트리 재확인 (이미 대부분 완료)

D에서 하지 않는 것

  • Map Objects → MapObjects 리네임 (→ F)
  • 무기 CSV 폴더 재배치
  • CharacterData를 Resources로 옮기거나 반대로 옮기기 (→ E와 연관)
D 완료 정의
“Data는 현 위치 유지가 정답이다”가 문서와 경로 체크로 증명되었거나, 빈 폴더 몇 개만 지운 상태로 컴파일/시트 동기화 스모크 OK.

E Phase E — Resources 경량화

E가 뭔가?

고위험

Resources/는 코드가 Resources.Load("경로")로 불러오는 특수 폴더입니다. 지금 대략 Animations 332 / Sprites ~2730 / Sounds 55 / Fonts 31 등. Archive는 1차에서 이미 삭제함. 남은 것도 “전부 Resources일 필요”는 없음.

현재 확인된 Load (건들면 코드 수정 필요)
  • Characters/HackerData, Characters/CyborgData — CharacterSelector
  • Fonts/Maplestory Light SDF — SettingsUI, DamageText
  • Sprites/UI/SPR_MENU UI — SettingsUI

E-1 — Load 사용처 전수 조사 (필수, 이동 없음)

먼저 함
하는 일
전체 프로젝트에서 Resources.Load / LoadAll / 문자열 경로 grep. “Resources에 있어야 하는 목록(화이트리스트)” vs “빼도 되는 목록” 표를 HTML로 고정.
산출
docs/worklog-resources-inventory-….html

AC

  • Load 경로 목록 완성 (파일·라인)
  • 화이트리스트 / 이전 후보가 분리됨

E-2 — 미사용·비Load 자산만 이동

에셋 이동 · 코드 가능하면 안 건드림

목표 위치

  • Assets/Art/ — 앞으로의 정식 아트 (Scripts/Prefabs와 미러링)
  • 또는 확정 전 Assets/_Unused/ — 격리 후 한 버전 두고 삭제

1차로 빼는 후보 유형

  • Resources 안인데 Load 화이트리스트에 없는 스프라이트/애니 대량분
  • Resources/Animations/Objects/Hacking Objects 등 — Prefabs는 이미 Hacking으로 맞춰짐, 애니만 이름 어긋남 → E에서 Art/Hacking으로 정렬 가능(Load 여부 확인 후)
절대 E-2에서 바로 안 함
화이트리스트 경로(Fonts/…, Sprites/UI/SPR_MENU UI, Characters/…)를 코드 수정 없이 폴더만 옮기기.

AC

  • 이동 후 Play: Lobby/Main 스모크 OK
  • 화이트리스트 Load 전부 성공
  • 작업로그에 “뭘 Resources 밖으로 뺐는지” 목록

E-3 — Load 의존 제거 (선택 · 사실상 리팩터)

코드 수정 동반

CharacterData / 폰트 / 메뉴 스프라이트를 SerializeField·Addressables·직접 참조로 바꾸고 Resources 의존을 줄임. 이건 E의 “보너스”이고, 팀 승인 후 F와 붙여도 됨.

E 완료 정의 (최소)
E-1 인벤토리 완료 + E-2에서 비Load 자산 상당량 Art/_Unused로 이동 + 스모크 OK. E-3는 별도 승인.

F Phase F — 리네임 · Packages · 코드 리팩터

F가 뭔가?

고위험 · 폴더링 끝 다음

이름 규칙 통일, 안 쓰는 패키지 제거, namespace/구조 정리. 게임플레이 기능 추가는 아님.

F-1 — 공백 폴더명 제거 (PascalCase)

경로 문자열 + 습관 깨짐

대상 예

  • Map Objects → MapObjects
  • Drop Objects → DropObjects
  • Map 1 → Map1
  • Resources/Animations 쪽 공백·오타 폴더들

어떻게

  1. 리네임 맵 표 작성
  2. 에셋 이동(.meta 동반)
  3. BalancingSheetCatalog 등 하드코딩 경로 일괄 수정
  4. 시트 동기화·Play 스모크

AC

  • 공백 폴더(게임 콘텐츠 쪽) 0 또는 문서화된 예외만
  • Catalog/사운드 경로 컴파일·동기화 OK

F-2 — Packages 정리

manifest 변경
패키지계획조건
URP / 2D / TMP / uGUI / Test / IDE / GameAnalytics / MCP유지—
visualscripting제거 후보게임 그래프 없음 + ES3/빌드 문제 없을 때
localization제거 후보게임 번역 테이블 없음 + Odin 모듈 영향 확인
NuGetForUnity (빈 packages.config)제거 후보앞으로 NuGet 안 쓸 때
NativeWebSocket제거 후보Scripts 사용 0 확정 시
Timeline / Project Auditor팀 확인 후사용 여부

어떻게: 후보 1개씩 제거 → 컴파일 → Play. 절대 한 커밋에 전부 제거하지 않음.

F-3 — namespace · Managers 책임 · asmdef · 파일명 위생

본격 리팩터
  • namespace를 폴더 경로에 맞게 (NeoSurvive.UI, NeoSurvive.Audio …)
  • Managers에 남은 비매니저성 코드 추가 분리(이미 Audio/Lobby는 이동함)
  • 게임 코드 asmdef 도입 검토
  • Prefab 파일명 trailing space / 깨진 이름 정리
F 완료 정의
F-1 + F-2(합의된 패키지)까지면 “폴더·패키지 정리”로는 충분. F-3는 별도 리팩터 마일스톤으로 쪼개는 것을 추천.

4 실행 순서 (고정)

  4. E-2 비Load 자산 → Art/_Unused (여러 PR 가능)

  6. F-1 공백 폴더명 + Catalog 경로 수정
  7. F-2 Packages 하나씩 제거
  8. F-3 namespace 등 — 별도 승인
