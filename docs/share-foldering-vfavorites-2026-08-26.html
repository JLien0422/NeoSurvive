NeoSurvive — Assets 폴더링 & vFavorites 활용

팀 공유용 요약 · 2026-08-26 · 브랜치 chore/assets-cleanup-unused · 관련 PR #12

목적 팀원이 Assets 구조를 같은 기준으로 쓰고, Project 창에서 vFavorites / Folder Dock을 바로 쓰게 한다.

1. Assets 폴더링 결과 (현재 구조)

도메인 단위로 정리했다. Unity 특수 폴더(Resources, Plugins) 이름은 바꾸지 않는다.

폴더역할비고
Scripts게임 로직UI / Audio / Lobby 등 도메인 하위
Prefabs조립된 오브젝트Hacking 등
Data밸런싱·스탯 데이터CSV/시트 연동
Art애니·사운드·스프라이트 등Resources에서 대량 이동(Phase E)
ScenesLobby / MainBuild Settings도 이 둘만
Resources런타임 Load 전용이름 변경 금지
Plugins / TextMesh Pro / vFavorites …벤더·툴임의 rename 금지

진행한 단계 요약

  • Phase A~C — 미사용 삭제, Scripts/Prefabs 이동, 작업 로그
  • Phase D — Data 경로/카탈로그 정리 (docs/worklog-phase-d-data-2026-08-26.html)
  • Phase E — Animations/Sounds/Sprites 등 → Assets/Art/ (docs/worklog-phase-e-resources-art-2026-08-26.html)
  • Phase F — 빈 폴더·미사용 패키지·Archive 씬 삭제 (docs/worklog-phase-f-unused-delete-2026-08-26.html)

숫자 prefix(01_Art …)로 정렬하는 방식은 채택하지 않음. Unity 특수 폴더·벤더 폴더 rename 리스크가 커서 vFavorites로 대체.

2. vFavorites 기본 사용법

  1. Project 창에 포커스
  2. Alt 길게 → 왼쪽(또는 오버레이)에 즐겨찾기
  3. 폴더/에셋/씬 오브젝트를 드래그해서 등록
  4. 페이지는 1~9 / ◀▶ / 스크롤로 이동
  5. 데이터: Assets/vFavorites/vFavorites Data.asset (커밋하면 팀 공유)

폴더 색은 vFavorites만으로는 불가 → 필요 시 vFolders 2.

추천 즐겨찾기 순서 (중요도)

  1. Scripts
  2. Prefabs
  3. Data
  4. Scenes
  5. Art
  6. Resources

3. Folder Dock (Project 창 통합)

별도 패널이 아니라 Project 창 하단에서 DefaultPage ↔ vFavorites Page를 넘긴다.

화면내용
DefaultPage 일반 Project 트리 (폴더 안 파일 탐색·스크롤 가능)
Page 1… vFavorites에 등록한 즐겨찾기 목록
고정 창 버튼 Page(vFavorites)에서만 표시. ON이면 Alt 없이도 하단 바/고정 유지
  • Unity 시작 시 Pin이 켜져 있으면 Project 고정 시도
  • 닫기(A): Pin 끄면 유지 안 함 → 나중에 Page에서 「고정 창」으로 다시 ON
  • 메뉴 안내: Tools → NeoSurvive → Folder Dock

관련 코드 (로컬 / 미커밋일 수 있음)

  • Assets/Scripts/Editor/FolderDock/
  • Assets/vFavorites/FolderDockPinToggle.cs
  • Assets/vFavorites/VFavorites.cs (DefaultPage / Pin / 스크롤 패치)

4. 하지 말 것

  • Resources / Plugins 폴더명 변경
  • 탐색기에서 대량 폴더 이동 (Unity 에디터 안에서 이동)
  • 벤더 폴더(TMP, ParrelSync, vFavorites 본체 등) 임의 rename
