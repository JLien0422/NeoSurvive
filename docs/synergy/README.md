# 해커 시너지 태그

## 목적

해커 무기에 부여된 태그를 현재 보유 무기 수로 집계한다. 같은 태그를 가진 해커 무기를 모두 보유하면 해당 태그는 활성 상태가 된다.

## 현재 구현 범위

- 무기 데이터에 태그 2개 저장
- 보유 무기 기준 현재 스택과 최대 스택 계산
- 좌측 중앙 HUD에 `현재 / 최대`와 활성 상태 표시
- 화면 왼쪽 가장자리 마우스 호버 시 HUD 슬라이드 표시
- 무기 선택 카드에 선택 후 예상 스택 표시

## HUD 구성 기준

시너지 HUD는 게임의 해킹·사이버네틱 분위기에 맞춰 어두운 청색 패널, 청록색 라인, 태그별 포인트 색상을 사용한다. 전투 화면을 가리지 않도록 평소에는 화면 왼쪽에 접어 두고, 마우스를 왼쪽 가장자리에 올리면 펼친다.

각 시너지 행은 다음 순서로 표시한다.

`태그 아이콘 배지 | 태그 이름 | 현재 스택 / 최대 스택`

현재는 별도 아이콘 원화가 없으므로 태그별 색상과 한 글자 배지를 임시 아이콘으로 사용한다. 최종 아이콘이 준비되면 같은 위치의 이미지로 교체한다.

최대 스택을 달성한 시너지는 다음과 같이 강조한다.

- 활성 시너지를 목록 상단으로 자동 정렬
- 행 배경의 청록색 밝기 강화
- 아웃라인 색상과 두께 강화
- 이름과 스택 숫자를 활성 색상으로 변경

후속 UI 연출 후보는 활성 순간의 짧은 글로우, 아이콘 펄스, 스택 증가 시 숫자 팝, 최대 달성 효과음이다. 반복 플레이를 방해하지 않도록 짧은 연출로 제한한다.
