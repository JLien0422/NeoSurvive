목표: 안 쓰는 것 삭제 우선. 코드 리팩터·Scripts/Prefabs 대규모 이동은 이번 PR에 포함하지 않음.

완료 · 작업 내역 기록

1. 한 줄 요약

빈 폴더, TMP/DOTween/Dictionary 예제, Resources archive/temp, 임시 씬을 삭제하고, 실험 씬 2개는 Scenes/_Archive/로 옮겼습니다. Build Settings는 Lobby + Main만 남겼습니다.

2. 삭제한 것

빈 폴더

삭제
Assets/Scripts/Items/

뭐하는 자리였나: 아이템 스크립트용 예약 폴더. 파일이 없어서 삭제.

삭제
Assets/Scripts/Hacking/ObjectManager/ , Reward/

뭐하는 자리였나: 해킹 오브젝트 관리/보상 코드 예약. 비어 있어서 삭제. 실제 해킹 코드는 HackingSystem·Effects·MiniGame에 있음.

삭제
Assets/Scripts/Characters/Player/Weapon/Passive/

뭐하는 자리였나: 패시브 무기 스크립트 폴더. 비어 있어서 삭제.

삭제
Assets/Prefabs/Managers/

뭐하는 자리였나: 매니저 프리팹용. 비어 있어서 삭제.

삭제
Assets/Packages/

뭐하는 자리였나: Assets 안 빈 Packages 폴더. 진짜 패키지는 루트 Packages/. 헷갈림 제거.

예제 / 샘플

삭제
Assets/TextMesh Pro/Examples & Extras/

뭐하는 것이었나: TMP 학습용 예제 씬·샘플(~249 files). 게임 UI가 아님. TMP 본체는 유지.

삭제
Assets/SerializableDictionary/Example/

뭐하는 것이었나: SerializableDictionary 사용 예제. 라이브러리 본체는 유지.

삭제
Assets/Plugins/Demigiant/DOTweenPro Examples/

뭐하는 것이었나: DOTween 데모. DOTween 본체(연출용)는 유지.

Resources 쓰레기

삭제
Assets/Resources/Sprites/archive/

뭐하는 것이었나: 옛/후보 스프라이트 더미(~728 files). 코드·에셋 경로 문자열 참조 없음 확인 후 삭제.

삭제
Assets/Resources/Sprites/UI/Archive/

뭐하는 것이었나: UI 스프라이트 아카이브(~8332 files). 경로 문자열 참조 없음 확인 후 삭제. Resources 경량화 목적.

삭제
Assets/Resources/Sounds/SFX/temp/

뭐하는 것이었나: 임시 효과음 폴더. 참조 경로 없음 확인 후 삭제.

임시 씬 (완전 삭제)

삭제
LobbyScene temp.unity , LobbyScene_TEMPPPPP.unity , MainScene_Temp.unity

뭐하는 것이었나: 작업용 복사/실험 씬. 정식 씬이 아님.

3. 이동한 것

이동
JmgScene.unity , Trick2Scene.unity → Assets/Scenes/_Archive/

뭐하는 것이었나: 개인/실험 씬으로 보임. 바로 지우지 않고 아카이브로 격리. 정식은 Lobby/Main만.

4. 설정 변경

수정
ProjectSettings/EditorBuildSettings.asset

Build Settings 씬 목록을 LobbyScene + MainScene만 남김. 삭제된 MainScene_Temp, 없는 lhsScene/multiScene, 아카이브로 뺀 Trick2/Jmg 엔트리 제거.

5. 이번 작업에서 안 한 것

  • Scripts WeaponChoice / Audio / Lobby 이동 (다음 Phase)
  • Prefabs Hacking 폴더 승격 (다음 Phase)
  • Packages(manifest) 제거 (Visual Scripting 등) — 조사 후
  • 코드/namespace 리팩터
  • Plugins 본체, Data CSV, Resources 전체 구조 변경
  • 이미 dirty였던 AllIn1/ES3/LobbyScene 등 무관 변경은 커밋에 넣지 않음

6. 확인(스모크) 권장

  • Unity에서 프로젝트 리임포트 후 Compile Error 없는지
  • LobbyScene / MainScene 로드
  • 콘솔에 Missing 스프라이트(옛 Archive GUID) 경고가 있는지 — 있으면 알려 주세요
  • UI 글자(TMP) 정상 표시 (Examples만 지웠으므로 본체는 유지)
Archive 스프라이트는 경로 문자열 참조는 없었습니다. 만약 Prefab이 GUID로 옛 아카이브 이미지를 잡고 있었다면 Missing이 날 수 있습니다. 그때는 해당 프리팹만 교체하면 됩니다.
