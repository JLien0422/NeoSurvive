이동 Prefabs/Objects/Hacking Objects/* → Prefabs/Hacking/

해킹 장치·UI 프리팹 (ElectricFence, MagneticBeacon, SatelliteUplink, SecurityTurret, SynapseServer, CaptureUI, HackInteractPrompt, Tutorial 버튼). Scripts는 이미 Hacking이라 Prefabs도 맞춤.

4. 안 한 것 (다음 / 보류)

  • Packages(manifest) 제거 — Visual Scripting, Localization 등 조사 후
  • Data CSV 경로 이동 — BalancingSheetCatalog 하드코딩
  • Resources 전체 → Art — Load 경로 위험
  • 공백 폴더명 리네임 (Map Objects 등)
  • namespace / 클래스 리팩터 / asmdef
  • 깨진 Prefab 파일명·trailing space 리네임

5. 스모크 체크 (주인님/팀)

  • Unity 리임포트 → Compile Error 0
  • LobbyScene: 캐릭터 선택, 로비 사운드
  • MainScene: 이동/공격, 무기 선택 UI, 해킹 오브젝트 1회
  • Missing Script / Missing Prefab / Missing 스프라이트(옛 Archive GUID) 없는지
스크립트·프리팹은 .meta와 함께 이동했습니다. GUID 참조는 유지되는 것이 정상입니다. Archive 이미지는 경로 문자열 참조는 없었으나, GUID로만 묶인 잔여가 있으면 Missing이 날 수 있습니다.
