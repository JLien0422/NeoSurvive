피드백 분류 정리

1. 코드 수정만으로 즉시 가능한 것

[옵션/버그]
- 오른쪽 하단 설정 닫기 버튼이 작동하지 않음
- 상자를 먹고 ESC를 누르면 퍼즈가 풀림
- 퍼즈를 건 상태에서 발생하는 이슈 확인 및 수정

[밸런스/전투]
- 경험치 획득 속도가 너무 빠름
- 수류탄 폭발 범위가 작음
- 광분 지속 시간이 김
- 공격속도와 공격범위 증가
- 기본 이동속도가 너무 느림
- 탄환 사거리 무제한 수정
- 몬스터가 플레이어에게 너무 쉽게 밀림
- 몬스터 리젠 수 증가
- 몬스터 공격속도/공격범위 증가
- 원거리 몬스터 스폰률 감소
- 포위 패턴 난이도 증가
- 용수철 선 맞추는 미니게임 난이도 완화

[인터페이스]
- 캐릭터 선택 창에서 선택된 캐릭터 테두리 표시
- 대미지/DPM 표 화면에서 무기 이름이 제대로 나오지 않는 문제 수정
- 오른쪽 상단 아이템 수집 여부 표시 제거 또는 축소 검토 후 반영
- 하단 게이지 UI 일부 정리 또는 표시 조건 조정

2. 리소스 추가가 필요한 것

[전투/피격 연출]
- 분신 애니메이션이 작동하지 않음
  - 단순 연결 문제면 코드 수정
  - 애니메이션 리소스가 없거나 부족하면 리소스 필요
- 캐릭터 피격 효과음 추가
- 캐릭터 피격 이펙트 추가
- 화면 임팩트, 번쩍임, 타격감 강화
- 스킬 사용 가능 여부를 화면 주변 이펙트로 표현

[아이템]
- 체력 회복 아이템 추가
  - 기존 아이템 시스템이 있으면 코드/데이터 수정으로 가능
  - 아이콘, 이펙트, 사운드까지 필요하면 리소스 필요

[맵]
- 사이버펑크 분위기에 맞는 맵 비주얼 개선
- 바닥 채도 수정
- 연구실 바닥, 타일 바닥 등 다양한 바닥 타일 추가
- 벽, 구조물, 오브젝트 추가

3. 새로운 알고리즘/시스템이 필요한 것

[게임 플레이/전투 방식]
- 자동 타겟팅 중심 공격에서 마우스 방향 기반 공격으로 변경
- 마우스 이동 방향에 따라 무기 공격 위치가 따라가도록 변경
- 근접 캐릭터 사이보그의 무기/스킬 사용 거리감 축소
- 원거리/근접 캐릭터별 공격 위치 계산 방식 분리 가능성 검토

[성장/보상 시스템]
- 무기 강화 상자 시스템과 경험치 레벨업 무기 선택 시스템 통합
- 상자 위치를 잊어 강화를 못하는 문제를 성장 시스템 구조에서 해결

[사이코 잠식도]
- 사이코 잠식도를 극단적인 양날의 검 구조로 재설계
- 리스크/보상 수치, 발동 조건, 누적/해소 방식 설계 필요

[UI 시스템]
- 적에게 들어가는 대미지 숫자를 작은 체력바로 대체
- 적 체력바 표시 조건, 개수 제한, 성능 최적화 필요

4. 기획 판단/확인 필요

[인터페이스]
- 게임 시작 후 화면 게이지가 너무 많은 문제
- 경험치와 무기 선택창의 관계성이 모호한 문제
- 해킹/신경 링크 게이지를 유지할지, 이펙트 중심으로 바꿀지 결정 필요
- 오른쪽 상단 아이템 수집 여부 표시가 필요한지 결정 필요
- 아이템 수집 기록을 사망 후 기록 화면에서만 보여줄지 결정 필요

[전투/피드백]
- 대미지 숫자 표기를 유지할지, 적 체력바로 바꿀지 결정 필요
- 화면이 뱀서류처럼 번쩍이고 임팩트 있어야 한다는 방향성을 어느 정도까지 가져갈지 결정 필요

[빌드]
- 현재 Mono 방식으로 빌드한 이유 확인
- IL2CPP로 전환할지 결정
- 스토어 업로드 제한, 성능, 보안 이슈 확인 필요

[미완성 피드백]
- "퍼즈를 건 상태에서" 항목은 문장이 끊겨 있어서 정확한 문제 확인 필요

5. 필요 없거나 보류해도 되는 것

[현재 기준 보류]
- 오른쪽 상단 아이템 수집 여부 표시
  - 완전 삭제보다는 사망 후 기록 화면으로 이동하는 방향이 더 합리적일 수 있음
- 대미지 숫자 표기 제거
  - 체력바로 바꾸면 화면은 정리되지만, 타격감이 약해질 수 있어 바로 제거는 보류가 좋음
- 모든 스킬 쿨타임 UI를 이펙트로만 대체
  - 직관성은 좋아질 수 있지만 정보 전달력이 떨어질 수 있어 전체 제거는 보류

권장 진행 순서
- 1번 코드 수정 즉시 가능 항목부터 먼저 처리
- 4번 기획 판단 항목을 확정
- 2번 리소스 작업과 3번 시스템 작업으로 분리해서 진행
