# Neo Survive 기획 확정사항
작성일: 2026-07-30
상태: 팀 의견 반영 후 확정 (개발 진행 기준 문서)
관련: 기존 기획서.txt의 세계관/콘텐츠 상세는 유지하되, 아래 항목과 충돌하면 본 문서를 우선한다.

================================================================================
1. 장르 / 정체성 (확정)
================================================================================

열린 맵 뱀서라이크(Vampire Survivors) 유지
+ 한 판 완주형 로그라이트 구조
+ (선택) 가벼운 액션 가미

- 자동공격 유지
- Isaac식 방(룸) 구조 없음
- 맵은 열린 필드로 유지
- 맵 곳곳에 상점/자판기 등 상호작용 가능
- 건전형 액션으로 장르 전환하지 않음 (대시 등은 양념, 코어 아님)

================================================================================
2. 한 판 구조 (확정 방향)
================================================================================

- 맵1 클리어 후 로비 복귀하여 맵 선택하는 구조에서
  → 맵1 → 맵2 → 맵3 선형 완주 구조로 전환
- 사망 시 맵1부터 다시 시작 (로그라이트 특색 강화)
- 한 판 안에서 빌드가 쌓이고, 완주가 목표가 됨

※ 세부 페이즈 시간/보스 배치 수치는 추후 밸런스

================================================================================
3. 성장 루프 (확정)
================================================================================

[메인] 레벨업 → 3택 1
- 미보유 무기 획득
- 보유 무기 레벨업
- 패시브
→ 위 항목이 한 풀에서 섞여 제시됨 (뱀서식)

[상자] 무기 강화 역할 제거 (기존 C안)
- 상자는 유물 / 특성 / 골드 등 다른 보상으로 변경
- 무기 성장은 레벨업 3택이 담당

[상점] 맵 곳곳 상호작용 (자판기 등)
- 한 판 영구 특성/유물을 구매·선택
- 메타(로비) 영구 특성이 아니라, 단판(런) 영구 시스템
- 상세 가격곡선(살수록 비싸짐 등)은 추후 밸런스

================================================================================
4. 해킹 시스템 (확정) ★
================================================================================

| 항목 | 내용 | 비고 |
| --- | --- | --- |
| 타이밍 | 포위(정해진 타이밍)에 해킹 수행 | 플레이어 임의 타이밍 해킹은 비채택 |
| 흐름 1 | 포위 패턴 발생 | 정해진 타이밍 |
| 흐름 2 | 해킹 수행 | 포위 구간 중 진행 |
| 흐름 3 | 성공 시 상자 드롭 | 무기 강화 상자 아님 |
| 흐름 4 | 상자에서 보상 획득 | 한 판 영구 특성 또는 유물 (3택 권장) |
| 해킹의 역할 | 포위 구간의 고보상 이벤트 | — |
| 보상 창구 | 상자와 동일 계열 | 한 판 영구 특성/유물 |
| 무기 강화 | 하지 않음 | 레벨업 3택과 역할 분리 |
| 미결: 실패 페널티 | 사이코 잠식도 유지 여부 / 보상 없음만인지 | 추후 확정 |
| 미결: 미니게임 | 유지 / 단순화 여부 | 추후 확정 |
| 미결: 풀 공유 | 상점 3택과 특성·유물 풀 공유 여부 | **공유 권장** |

================================================================================
5. 전투 / 연출 (확정)
================================================================================

- Normal 몹 수 대폭 증가
  - 핵앤슬래시로 쓸어담는 쾌감
  - 위기감 연출
- 타격감·이펙트 강화 (눈뽕/임팩트) — 우선 적용 대상

================================================================================
6. 우선순위 컷 (지금 / 나중에 / 거절)
================================================================================

[지금 넣을 것]
- Normal 몹 대폭 증가
- 레벨업 무기/패시브 3택
- 상자 = 무기 강화 아님 (특성/유물/골드 등)
- 맵 곳곳 상점/자판기식 3택 (런 내 성장)
- 특성 = 메타 영구 X, 한 판 영구 O
- 맵1→2→3 선형 완주, 사망 시 처음부터
- 타격감·이펙트 강화
- 해킹 = 포위 고정 타이밍 + 성공 시 상자(한 판 영구 특성/유물)

[나중에]
- 무기 융합 / 시너지
- 보스 클리어 보스유물
- 대시/구르기 등 가벼운 액션
- 쓰레기장 오브젝트·맵 비주얼 밀도
- 아트 업스케일
- 단발/영구/액티브/패시브 아이템 세분화
- 로비 베이스/메타 강화
- 상점 가격 상승 곡선 등 세부 밸런스

[거절·강하게 보류]
- Isaac식 방 구조
- 장르를 건전 액션으로 전환
- QTE를 전투 코어로 사용
- 해킹 삭제 후 대체 없음
- 메타 상점만으로 “할 이유” 해결
- 상자·레벨업·자판기·해킹을 역할 없이 전부 별도 시스템으로 병행
  → 창구는 레벨업 / 상점 / 상자(해킹 보상 포함)로 역할 분리

================================================================================
7. 한 줄 요약
================================================================================

물량으로 압박하고,
레벨업 3택으로 무기를 키우고,
포위 해킹 상자·맵 상점으로 한 판 특성/유물을 쌓아
맵1→2→3을 완주하는 열린 맵 뱀서 로그라이트.
